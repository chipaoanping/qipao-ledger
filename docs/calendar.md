# 今日預約：從 Google 日曆帶入顧客姓名、電話

結帳時按「顧客」旁邊的「**今日預約**」，會列出這家店今天日曆上的預約。點一筆，就會自動填入姓名和電話，並跟著這筆交易存起來。

- 旗跑・安平讀「旗跑」日曆，旗時・永樂讀「旗時」日曆。
- TinyBook 的預約會讀「顧客」和「聯絡電話」。顧客是「訪客」時，改用標題最前面的名字。
- 自己建的預約，會用標題「｜」前面的字當姓名。說明裡有手機號碼的話，也會帶入。
- 已經結帳過的預約會標「已結帳」。
- 姓名和電話也可以直接手打。

## 設定（只要做一次，大約 5 分鐘）

用**店裡的 Google 帳號**（看得到這兩個日曆的那個）操作。

1. 打開 https://script.google.com ，按「新專案」，專案名稱改成「POS 今日預約」。
2. 把 GitHub 上 `apps-script/pos-calendar.gs` 的內容全部貼上，取代原本的程式碼，然後按儲存。
3. 上方的函式選單選 `makeKey`，按「執行」。
   - 第一次會要求授權：選店裡的帳號 →「進階」→「前往 POS 今日預約」→「允許」。
   - 下方的「執行紀錄」會顯示 `key = …`。先把它複製起來。
4. 右上角按「部署」→「新增部署作業」。
   - 類型選「網頁應用程式」。
   - 執行身分選「我」。
   - 誰可以存取選「所有人」。
   - 按「部署」，然後複製「網頁應用程式網址」，它的結尾是 `/exec`。
5. 在網址後面加上 `?key=` 和剛剛的 key，例如：
   `https://script.google.com/macros/s/AKfy…/exec?key=1a2b3c…`
6. 用妃妃或郁雯的帳號登入 POS，到「設定」→「預約日曆」，貼上這個網址，按「儲存」。

## 安全

- 有完整網址（含 key）的人，就能看到當天的預約姓名和電話。所以這個網址只貼在 POS 的設定裡，**不要**放到 GitHub、群組或公開的地方。
- 網址外流的話，再執行一次 `makeKey` 換一個新的 key，然後把 POS 設定裡的網址換成新的 key。舊的網址就會失效。
- 程式只會讀日曆，不會修改日曆。

## 之後改了程式

如果 `pos-calendar.gs` 有更新：貼上新的內容 →「部署」→「管理部署作業」→ 編輯（鉛筆）→ 版本選「新版本」→「部署」。網址和 key 都不會變。
